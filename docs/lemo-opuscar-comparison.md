## 二、已覆盖类里的形态缺口（它有、咱们没有、形态差异明显）

剪辑纪实类：

- Visual Investigation 视觉调查：多路证据（影像、照片、文件、声音、地图）压到同一条时钟上互相印证；时间以画面内的大读数、秒表、冻帧呈现，关键帧圈点放大，引文直接在原页上高亮，已知与未知分栏摆着，不确定处用虚线框与「推断」字样画出来，收尾全部证据汇成一张地图。咱们 wall 有证据墙骨架（照片、红线、印章），但没有「同钟对照、画面内时钟、已知未知分栏」这套核查语法——这是核实模板最值得补的一层。
- Broadcast News Package 电视新闻包装：主播台、下三分之一字幕条、台标、滚动字幕一整套电视包装语法。咱们有字幕烧录，但没有这套包装件，剪报是纸面路线、不是荧屏路线。
- Live Countdown Split-screen 实时倒计时分屏：多画面同屏并行＋大倒计时制造张力。咱们全片单画面到底，没有分屏构图件。
- 1920s Newsreel 新闻影片、Constructivist Montage 构成主义蒙太奇、City Symphony 城市交响曲：分别是旧新闻片质感、几何蒙太奇剪辑、无旁白纯画面交响——三种「剪辑本身即风格」的形态，咱们的剪辑语法只有单镜推拉。
- Sports Telestrator 体育战术板：冻帧上画战术线与圈点。形态小众，但「冻帧＋标注」的手法可迁移到核实片的画面讲解。

速写板书类：

- Sketchnote 视觉笔记：手绘元素与文字混排成一页笔记式版面（箭头、气泡、小图标、分区），是教程与科普的高亲和版面。咱们的白板是「边画边讲」的线条页，没有这种成品笔记版面。
- Tablet Sketch Explainer 平板速写、Marker on Paper 马克笔白纸：同为手绘讲解，差别在纸面与笔触质感（平板的干净线、马克笔的粗头与渗墨）。与 whiteboard 属近亲升级，差异中等。
- One-line Drawing 一笔画：一条线不断笔走完全片。形态辨识度极高，但叙事承载有限。

印刷版画类：

- Halftone Dossier 网点档案：照片与明暗全部网点化、几色油墨套印错版、奶油纸案卷加重标题与编号展品。是咱们 archive 卷宗与 newsprint 剪报的近亲升级——「照片变网点」这一手咱们没有。
- Risograph 孔版、Woodcut 木刻、Copperplate Engraving 铜版、Silkscreen Poster 丝印海报、Pop Art 波普、Vintage Collage 版画拼贴、Scratchboard Long Take 刮版长镜头：整组版画质感咱们皆无，其中丝印海报与波普偏海报装饰，木刻与铜版偏传记氛围。

平面排版类：

- Swiss Motion Graphics 瑞士动态排版：网格、左对齐、无衬线大字的动态排版基本功，百搭型。咱们 product 有发布感，但不是排版语法。
- Text Flash Cuts 文字闪切：全屏重字卡以两到九帧的极短时长切入切出、红黑白三色、竖排字柱，节奏全靠剪辑与字卡（其人物部分依赖图像生成，纯字卡部分可自写实现）。竖屏短视频的强节奏件。
- Pictogram Motion 象形运动图形、Bauhaus Shapes 包豪斯几何、Scale Zoom Explainer 尺度漫游（靠连续缩放讲数量级）、Silhouette Rhythm 剪影律动、Art Deco 装饰艺术、60s Spy Titles 间谍片头：多为片头与装饰形态，尺度漫游对科普教程有借用价值。

线稿图解类（教程硬通货最集中）：

- Exploded Teardown 产品拆解：真实产品按轴分层拉开、零件逐个引线命名、再合拢。对方用真 3D 渲染，咱们 2D 引擎做不了照片级拆解，但「分层拉开＋引线标注」的构图语法可 2D 化（照片分层＋StringLine 引线）。
- Line-Art Cutaway 线稿剖面：剖开外壳画内部结构的剖面图语法。咱们蓝图是平面制图，没有剖面件。
- Instruction Manual Art 说明书插画：分步骤编号图、箭头与操作示意的说明书语法。教程模板现在靠图卡堆叠，没有步骤图件。
- Color-Coded Mechanism 分色机械图解：不同系统不同颜色的机械原理图。咱们 charts 有分色图表，但不是机械结构图。
- Assembly-Line Diagram 流水线图解：工序沿线流动的图解，讲流程与生产题材合用。

屏幕界面类：

- Mascot Screencast 录屏讲解：界面不用真录屏，而是把软件界面用代码逐像素重绘成「假录屏」，镜头可任意推拉、文字永远锐利，再放一个低分辨率像素角色在界面里替软件「表演」操作。咱们的软件类教程只能贴图卡，没有这种可动界面。
- Dark Tech Keynote 暗色科技发布：黑场、单品打光、大字卖点的发布会语法。咱们 product 偏霓虹宣传感，与此形态有别，项目发布片可用。
- Spreadsheet Film 表格动画：电子表格的格子、公式与高亮当演员，讲数据与财务题材的专门形态。
- Sci-fi Hologram HUD 全息界面、Desktop Flythrough 桌面穿梭、1-bit Dither 点阵：偏科幻与实验，与咱们用途弱相关。

仪器实证类（核实片的证据新形态）：

- Satellite Briefing 卫星简报：以卫星图为底、从轨道高度一路推近到地面目标的简报形态，地理类核实（灾害、工程、地貌变化）的当家形态。咱们地图之旅是路线叙事，没有卫星图层。
- Engineering Briefing Board 工程简报板：一面带擦痕与窗光的真实白板墙当摄影对象，真实物体照片抠像贴上墙、三色记号笔各有固定含义、镜头沿线旅行、全片最后一镜才拉出整面墙。与咱们 wall 的「整墙收尾」相通，但它是被拍的实体墙＋照片抠像，咱们是软木板贴图，形态有别。
- Archive Light Table 档案看片台：胶片与底片在灯台上逐张审看的形态，与咱们卷宗近亲，差别在「光台＋胶片」介质。
- Thermal Camera 热成像、Security X-ray 安检透视、Radar Sweep Documentary 雷达扫描、LiDAR Survey 点云测绘、Under the Microscope 显微叙事：五种成像类证据形态，分别对应夜间与建筑、安检、空域与海洋、考古与地形、微观世界题材，皆为咱们所无。

数据地图类：

- Data Physicalization 数据实物化：数据变成可数的实物（堆叠、螺旋、阵列）在画面里生长。咱们 infographic 是平面图表，没有实物化形态。
- Blob Simulation 小人模拟实验：成群小人按规则行动来演示机制（排队、疏散、传播），科普说理的强形态。
- Transit Map 地铁线路图：网络线路图的生长与换乘语法。咱们 map-journey 是地理路线，不是网络图。
- Projection-Mapped Model 白模投影：数据投影在白色立体模型上。偏展览形态，成本高。

## 三、缺口排序（按咱们真实用途）

优先级一（直接增益核实、教程、传记三模板或中文受众、竖屏形态）：

1. 视觉调查的核查语法（同钟对照、画面内时钟、已知未知分栏、不确定性画法）——补进核实模板，是构图与规则层，不是新底纹。
2. 卫星简报——核实地理类选题的当家形态，咱们有地图底子可接。
3. 说明书步骤图＋线稿剖面＋分层拆解构图——教程模板三件，全是 2D 可落地件。
4. 录屏讲解形态——软件类教程的主力形态；实现路径与现有图卡管线不同（界面重绘），单列候选。
5. 中国水墨、红色窗花剪纸——传统工艺类里与中文受众、历史传记最贴的两款，国风辨识度高。
6. 搞笑历史卡通——纸偶站在印刷地图上、领土与局势变化用剪纸动作演，整片是一页漫画；传记与历史题材的轻量化形态，2D 可实现性高。
7. 文字闪切（纯字卡部分）——竖屏短视频的节奏件，咱们 BigText 有底子。

优先级二（明显增益，但要排队）：

8. 网点档案——卷宗与剪报的升级形态，照片网点化是新工序。
9. 工程简报板——核实与事故复盘可用，与证据墙分工（实体墙＋抠像照片）。
10. 电视新闻包装件（下三分之一字幕条等）——新闻类核实片的荧屏路线。
11. 视觉笔记版面——教程科普的亲和版面。
12. 瑞士动态排版——平面基本功，多模板百搭。
13. 漫画分格——竖屏叙事形态，条漫式分格推进。
14. 默片——传记与历史的氛围形态（字卡＋旧片质感）。
15. 分屏倒计时构图——事件类核实片的张力件。
16. 小人模拟——科普说理形态。
17. 暗色科技发布——项目发布片形态。
18. 热成像、安检透视、雷达扫描、点云、显微——仪器成像组，题材对上时逐个补。
19. 尺度漫游——科普数量级题材专用。
20. 数据实物化——数据片的进阶形态。

优先级三（纯装饰或与咱们路线弱相关，备案即可）：

- 绘画插画整类（水彩、油画厚涂、彩铅、蜡笔绘本、钢笔淡彩）：笔触类与咱们矢量墙面语法路线不同，落地成本高。
- 传统工艺其余（浮世绘、皮影、彩窗、金箔、纸雕灯）：水墨剪纸之外排后。
- 版画其余（孔版、木刻、铜版、丝印、波普、拼贴、刮版）：氛围与海报向。
- 卡通其余（橡皮管、赛璐璐、科幻情景剧、50s 扁平）：娱乐叙事向。
- 电子游戏整类（像素 RPG、HD-2D、微游戏、节奏综艺）。
- 立体微缩大部（积木、移轴、低多边形、玻璃产品、孟菲斯、蜡笔立体）：多依赖真 3D 管线；纸立体书可用 2D 造景近似，单列备案。
- 胶片录像实验组（后室、胶片直刻、双重曝光、CRT 字符）。
- 发光线条整类（电路板、萤火点光、流场风线、示波器数学、霓虹灯管）：氛围向，其中示波器数学与电路板对理科、科技教程有氛围价值，排本组前列。
- 全息界面、桌面穿梭、1-bit 点阵、白模投影、城市交响曲、构成主义蒙太奇。

## 四、双指南结构对照（只记结构与条目名）

对方 DIRECTOR.md（导演法，13 节）：接活与需求确认 → 先找标杆片 → 故事形状 → 写 treatment（拍摄方案）→ 证明长相（样帧先行，用户点头才全片；分镜为可选项）→ 声音是半部片 → 节奏（音乐网格先行）→ 镜头（每镜要有理由）→ 表演 → 高频失败清单 → 交付前清单 → 版权红线 → 地图（资料索引）。

对方 TECHNIQUE.md（工艺法，12 节）：环境与安装 → 画面是时间的函数 → 一条时间线驱动一切 → 配音 → 音乐 → 音效与混音 → 字幕 → 审片循环 → 3D 注记 → 代码画角色 → 素材、致谢与字体 → 样片导览。

咱们的文档现状：README（总览与中文补丁说明）、docs/DEPLOYMENT.md（部署配置）、docs/ROADMAP.md、CREDITS.md、styles 索引与 14 篇风格说明、5 个模板 README、引擎各模块 docstring（流水线、自检、字幕、素材台账等口径散在代码与模板里）。

工艺法一侧咱们大体齐：时间函数与单时间线（Doc 的 L/E/W 口径）、配音、字幕、审片（联系表工具）、素材与致谢与字体，都有对应模块，只是分散成文、没有汇成一篇总工艺。缺两节：代码画角色（咱们无角色系统，火柴人在外部短视频技能线）、3D 注记（无 3D 管线，与路线选择一致，不算短板）。

导演法一侧咱们缺的环节（点名）：

- 标杆先行：没有成文的「先找标杆、样帧经用户点头才全片」流程条目；现行做法靠聊天约定（如定版样片格式只记在仓外台账）。
- 故事形状与 treatment：三模板 README 有结构骨架，但没有独立的叙事结构与拍摄方案条目。
- 声音与节奏：有节拍与混音工具，但没有「声音设计＋音乐网格先行」的成文章节（背景音乐来源在咱们这边本就是悬置项）。
- 高频失败清单：教训散在仓外（字体字形退化、印章压图注、浅底白字等），仓内没有失败图鉴。
- 交付前清单：有联系表工具，没有成文的交付检查清单（红果线有出片前审计，那是另一条线的文档）。
- 版权红线专章：规则在素材抓取代码里（NC/ND 默认拒、许可证台账），没有汇成一章人读的红线。
