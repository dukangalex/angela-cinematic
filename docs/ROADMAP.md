# 扩展路线图（ROADMAP）

本仓以 cinematic-skill 与 motion-starter-kit 为跳板，不以其为边界。
扩展的取舍标准只有一条：让「一个主题进来、一部能看的片出去」这条路更短。

## 已落地（v1.1）

- **tts_takes.py**：正式配音直连。逐句合成（切句点干净）、按 take 拼轨、
  声线/语速/代理走部署配置；edge（云扬/Andrew）与任意命令两种后端。
- **make_film.py**：一键流水线。fetch→assets→takes→timing→render 分阶段、
  可续跑、可跳段；scene 缺失时明确停下，不假造。
- **contact_sheet.py**：联系表自检。逐句抽关键帧拼图编号，
  豆腐字、错位触发、版式崩坏在看全片之前先暴露。

## 已落地（v1.2）

- **scaffold_scene.py 场景脚手架**：从 script.json＋photos.json 生成
  scene.py 初稿（照片成排、镜头逐个拜访、typed 大字、数字计数器、
  结论印章），拒绝覆盖已存在的场景——初稿归作者改。
- **charts.py 图表组件**：BarChart / LineChart / Donut 三个数据原语，
  与引擎同一元素协议，生长/描线/扫掠动画，数据走普通列表。
- **vertical.py 竖屏预设**：五种画幅表＋按画幅的安全区比例＋SafeFrame
  辅助框（按镜头位姿画出平台 UI 安全带，草稿期用、成片前摘掉）。
- **stylepacks.py 风格代码包**：11 种预设落成代码参数（色板、字体槽、
  镜头速度），选风格从「读一份文档」变成「传一个参数」。

## 已落地（v1.3）

- **fetch_sources.py 素材源扩展**：Openverse 与 NASA 素材库接入 fetch 层，
  与 Commons 同一套许可证台账（署名、许可证、来源页逐条落盘，
  NC/ND 等非自由许可默认拒绝、单条失败不拖垮整批）。
- **双语字幕**：script.json 行内加 sub 字段，burn_captions --bilingual
  在 clean 样式下烧第二行小字（SRT 导出同步带副行）。
  顺带修掉一个上游潜伏问题：字体角色缺 CJK 字形时自动以项目内的
  CJK 字体替补——原先 clean 字幕的中文会整行变豆腐块。
- **templates/ 主题模板包**：核实（三段式＋结论印章）、教程
  （问题／步骤／验证）、传记（时间线）三套开箱模板，
  复制目录即新项目，占位旁白即结构说明。

## 后续

路线图三批已全部落地。之后的扩展按真实选题驱动：
哪条内容线先开工，就先补哪条线缺的组件，不再预排清单。

## 不做

- 不接生成式视频、不接拍摄素材：纯代码绘制是这条线的立身之本。
- 不为「以后可能用」先搭框架：每批扩展都要有当批的验收示例。
