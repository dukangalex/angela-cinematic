# 教程类模板

结构：问题 → 准备 → 步骤（每步一句旁白＋一张截图＋typed 步骤大字）
→ 验证与坑。步骤增减时同步改 script.json 的 takes 和 scene.py 里
(3, 4, 5) 的行号元组。截图一律自截，界面里的账号信息先打码。

## 图解三件（engine/diagrams.py，场景下半区已摆好示例）

光有截图不够，结构要画出来。三件都是 2D 线面现画、不吃素材，
用不上哪件删哪件：

- **步骤图 StepFlow**：编号方框＋箭头连成一条链。适合收尾复述
  或开头预告全程；每框标题＋一行说明，说明长了用换行符断成两行，
  不许塞小字。旁白讲到第几步，链就走到第几步（调 stagger 对齐）。
- **线条剖面 Cutaway**：画「打开看内部」。parts 每项是
  (标签, 横位置, 纵位置, 宽, 高, 标注侧)，位置都是壳内相对值；
  壳顶斜线带与 A—A 虚线是剖面标记，不要删——观众靠它认出这是剖面。
- **分层爆炸 ExplodedLayers**：画「由哪几层叠出来」。层板沿虚线
  导轨逐层拉开，标签在右侧对到本层；层数 3–5 层为宜，
  再多就分两次拆。适合配置构成、订阅结构、流水线分工这类题。
