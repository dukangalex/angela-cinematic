## 核查语法（engine/evidence.py，场景里已摆好，按实测改参数）

核实的说服力要落在画面上，不只靠旁白说。三件语法：

- **画内时钟 FrameClock**：压在证据图角上，读数就是证据自己的时间。
  start 填证据起始秒，倍速／慢放改 speed；关键一秒要定格时给 freeze，
  时钟会停在那一秒并亮出「冻帧」签。旁白里念到的每个时间点，
  画面时钟必须正好走到那里，对不上就改参数，不许将就。
- **同钟标尺 SyncRuler**：两路证据共用一把尺。pins 里两枚针的 frac
  相同就是同一时刻，虚线会穿过两份证据，观众自己能看出对没对齐。
  span 是证据全长秒数，标签写清哪路来源、第几秒。
- **已知／未知分栏 KnownUnknown**：查清的进左栏（实线、对勾），
  没查清的进右栏（虚线、问号）。凡是推断，条目写成 (文字, True)，
  画面自动挂红色「推断」签——不许把推断混进已知栏，
  也不许因为未知多就藏着不摆，未知摆出来本身就是核实的态度。
