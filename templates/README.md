# 主题模板包

按内容线沉淀的开箱模板：复制整个目录就是一个新项目，
占位旁白本身就是结构说明，照着换成真实内容即可。

| 模板 | 结构 | 适用 |
|---|---|---|
| verify | 说了什么 → 核实结果 → 有没有用＋结论印章 | 核实局、辟谣、数据打假 |
| tutorial | 问题 → 准备 → 步骤 → 验证与坑 | 博客教程转视频、工具教学 |
| bio | 起点 → 转折 → 关键战役 → 成名 → 落点 | 人物传记、品牌史、产品史 |

通用流程：改 script.json → photos.json 配图（fetch_commons /
fetch_sources 取图或自备截图）→ prep_assets → make_film →
contact_sheet 复查。模板场景里的示例数据（如核实模板的对照柱状图）
务必换成真实数字再出片。
