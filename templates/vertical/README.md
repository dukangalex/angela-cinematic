# 竖屏模板（9:16）

结构：标题（顶部安全带）→ 主图（居中）→ 结论章（下部安全带），三句旁白。

竖屏纪律（口径在 engine/vertical.py）：

- 出片尺寸 `--size 1080x1920`，草稿可先用 720x1280 同比例验构图。
- 可见世界：宽恒为 3840/zoom，高按比例放大（zoom 0.55 时约 6982×12412）。
  横屏习惯的左右铺开在这里行不通，元素一律竖排、居中。
- 安全带：顶部 13%、底部 20% 是平台界面（标题、按钮、进度条）的地盘，
  关键元素不进；定稿前用 scene.py 里注释掉的 SafeFrame 渲一张草稿帧核对。
- 镜头 zoom 常用 0.5–0.65：再小字会细，再大图会裁。
- 字幕照常烧 clean 样式；主字幕行在画面下部，避开底部安全带下沿即可。
- 选图优先竖幅或可裁竖幅的图；横幅图在竖屏里只剩一条，慎用。
