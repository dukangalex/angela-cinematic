# Example: Twelve Seconds (English)

The Wright brothers' first flight as an 89-second code-drawn documentary —
the upstream worked example, kept as the English reference project.
The Chinese edition lives in `../wright-zh/` with the same structure.

Run it with the steps in the repository README's quick start.
Narration takes go in `audio/takes/` (or use `engine/tts_say.py`
for a scratch voice); photos come from Wikimedia Commons with
per-photo license records.
