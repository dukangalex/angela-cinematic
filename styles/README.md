# 风格预设库

本目录是 angela-cinematic 的风格预设：一风格一份文件，描述这种风格在
Skia 引擎里怎么落地——底面、配色、镜头习惯、文字行为、可用元素。
写 scene.py 之前先选一份预设，按它的口径选 `Film(look=...)`、底纹和组件。

| id | 风格 | 一句话 |
|---|---|---|
| `wall` | 证据墙（引擎原生） | 软木墙上的照片、电报与印章，一镜到底的纪录片墙 |
| `plotter` | 绘图仪 | 笔尖带火花在方格纸上绘图，关键词随声亮起，全片只用 3 色 |
| `whiteboard` | 白板 | 马克笔边画边写，镜头逐段贴近，画完之后画面「活」过来 |
| `chalkboard` | 粉笔黑板 | 绿板上的粉笔字与粉尘，适合讲证明、推导 |
| `stickman` | 火柴人 | 白身火柴人主演的短剧式讲解，表情与音效撑场 |
| `isometric` | 等距世界 | 彩色等距世界里旅行，区域与阶段编号浮在上方 |
| `fake3d` | 伪 3D | 平面图形带柔光与厚度，单镜头无剪辑，收尾成海报 |
| `infographic` | 信息图 | 大数字滚动计数、图表无缝变形，发布会式排版 |
| `map-journey` | 地图之旅 | 古地图上沿路线飞行，站点插旗立卡 |
| `product` | 产品发布 | 大字由糊到清、霓虹描边、界面斜挂辉光的产品宣传片 |
| `doodle` | 涂鸦 | 墨水小人儿在同一世界里连续行走，逐词发光字幕，竖屏优先 |

预设的来源与致谢见仓库根目录 `CREDITS.md`：`wall` 是引擎原生风格；
其余 10 种按 motalim-ai/motion-starter-kit 的公开风格说明，
在本引擎里重新表达为 Skia 口径，未搬用其 Remotion 代码。
